# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through
[GitHub private vulnerability reporting](https://github.com/Marwan-G/pavedline/security/advisories/new)
or by contacting the maintainer via [LinkedIn](https://www.linkedin.com/in/marwan-ghubein/).

Include a description, reproduction steps and the affected version. You can expect an
acknowledgement within a few days.

## Scope

Pavedline ships workflow instructions, hooks and scripts that run inside Claude Code. Reports about
unsafe hook behavior, secret leakage, or unintended command execution are in scope.
