# Retros

One retro per wave, written by the `lessons` skill at step 11 and read by the founder.

File name: `<YYYY-MM-DD>.md`, from `0000-template.md`.

Each lesson ends in exactly one of three places: a rule in the one home `docs/rules-index.md` names, an intent in
`docs/intent/` (with `Source: retro <date>`), or dropped with a reason. Retros are append-only history; fix a wrong
lesson in a later retro.
