# Intent

An intent is a proposed change to the product, written before it is specced. The founder writes one, or `lessons`
at a retro, or an incident.

File name: `<YYYY-MM-DD>-<slug>.md`, from `0000-template.md`.

Flow: proposed → the founder accepts (`Status: accepted`) → `spec` change mode updates `docs/spec/SPEC.md` and
writes a decision → `plan-graph` plans it. A rejected intent stays here with its reason.
