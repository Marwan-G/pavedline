# Growth

The Grow loop's records. Written by the `growth` agent with the `content-ops` skill; the founder approves every publication.

| File | What it holds |
|---|---|
| `calendar.md` | the weekly content calendar: one row per planned piece |
| `YYYY-MM.md` | the monthly review: Search Console findings, the `seo-audit` result, actions taken and next |
| `briefs/<slug>.md` | one brief per piece: target query, intent, outline, sources |

`STATE.md ▶ GROW DUE` names the next run and its date. Nothing here is published until the founder's approval is recorded in the brief.
