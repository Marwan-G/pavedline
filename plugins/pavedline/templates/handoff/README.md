# Hand-offs

One file per working branch: `handoff/<branch>.md` (use `-` for `/` in the branch name). A session that is not the
`OWNER` writes its state here and never edits `STATE.md`. The owner folds the file into `STATE.md` when the branch
merges, then deletes it.

A hand-off says: what was done, what changed, what is left behind, and the exact next step.
