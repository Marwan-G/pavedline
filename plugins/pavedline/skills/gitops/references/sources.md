Installing the chart with its own CRDs on top failed on 2026-11-09: Helm 4 server-side apply conflicts with the existing Gateway API CRDs (the chart bundles v1.6.1, experimental channel). | `helm show values` of the chart (`crds.enabled`) |
| Why Envoy Gateway | A conformant Gateway API controller with Apache-2.0 licence, a published compatibility matrix and an OCI chart; the proxy Service can be a fixed NodePort through `EnvoyProxy`, which the kind port mapping needs. | https://gateway.envoyproxy.io/docs/ |
